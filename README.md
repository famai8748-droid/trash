## 🌟 จุดเด่นและฟีเจอร์หลัก (Key Features)

### 1. 📷 AI Vision Waste Scanner & Fine-Tuned Material Cockpit
- **ระบบสแกนเนอร์มุมมองค็อกพิทลักชัวรี (Alt + S):** เล็งกล้องสด (Live Camera WebRTC) หรืออัปโหลดภาพขยะหาดบางแสน
- **Fine-Tuned Multi-Object Detection Mockup:** ตรวจจับและตีกรอบ Bounding Box แยกประเภทขยะพร้อมกันในเฟรมเดียว (Multi-Class) ด้วยความแม่นยำสูง:
  - 🍫 **ซองขนมกรุบกรอบ / ถุงฟอยล์ (Foil Snack Wrapper)** — กล่องทองอำพัน (Amber Gold)
  - 🍶 **ขวดน้ำดื่มพลาสติกใส PET #1 (Clear PET Bottle)** — กล่องฟ้าคริสตัล (Sky Blue)
  - 🧴 **ฝาขวดน้ำพลาสติก HDPE #2 (Ocean Bottle Caps)** — กล่องเขียวมรกต (Emerald Green)
  - 🌊 **แก้วทะเลขัดเงาธรรมชาติ (Sea Glass)** — กล่องเขียวพาสเทล (Teal)
  - 🥫 **กระป๋องอะลูมิเนียม (Aluminum Cans)** — กล่องม่วงนีออน (Purple)
- **Interactive Focus:** คลิกที่กล่องตรวจจับบนหน้ากล้องเพื่อเจาะจงโฟกัสที่ชิ้นนั้นๆ
- **AI Material Fingerprint & Instant Buyout:** คำนวณน้ำหนักประเมิน, ราคารับซื้อเป็นเงินสด, ปริมาณการลดก๊าซเรือนกระจก ($CO_2e$) และส่งตรงไปยังหน้าขายขยะได้ในคลิกเดียว
- **Generative Novel Concept:** สังเคราะห์ไอเดียนอกกรอบระดับผลงานศิลป์ Avant-Garde พร้อมราคาประเมินตลาด
- **Fine-Tuning Benchmark Matrix:** แสดงสถิติโมเดล YOLOv9, Confusion Matrix, Latency 18.4ms, และค่า mAP@0.5 สูงถึง 98.6%

### 2. 📖 Open-Source Upcycle Blueprint & Circular Academy
- คลังสูตรพิมพ์เขียวขั้นตอนการแปลงขยะเป็นงานหัตถศิลป์มูลค่าสูง
  - *bp-1:* สร้อยคอหินแก้วทะเลบางแสน (Sea Glass Pendant)
  - *bp-2:* แว่นกันแดด Terrazzo ฝาขวดน้ำ HDPE
  - *bp-3:* นาฬิกาตั้งโต๊ะ Kinetic เฟืองจักรกล & อะลูมิเนียม
  - *bp-4:* โคมไฟประติมากรรมแก้วทะเลลักชัวรี
  - *bp-5:* กระเป๋าคลัตช์และซองแท็บเล็ตฟอยล์ซองขนมกันน้ำ
  - *bp-6:* แจกันเรขาคณิตขวด PET รีดเกลียวสะท้อนแสง
- แสดงรายละเอียดระดับความยาก, เวลาที่ใช้, อุปกรณ์, ขั้นตอน DIY แบบทีละขั้น และราคาขายที่แนะนำ

### 3. 🛍️ Luxury Craft Marketplace & Immersive Viewing
- ดีไซน์ระดับไฮเอนด์ (Rich Luxury Theme) ด้วยไวยากรณ์สไตล์หรูหรา ฟอนต์ Cinzel + Plus Jakarta Sans
- **Immersive Multi-Angle Modal:** ระบบกดดูสินค้าที่ซูมลอยเข้ามาสู่สายตาอย่างนุ่มนวล พร้อมปุ่มสลับมุมมอง (ภาพหน้าตรง, ภาพมุมเฉียง, ภาพดีเทลซูมลึก, ภาพขณะสวมใส่/จัดวางบนร่างกาย)
- **Interactive 3D Tilt:** แผ่นการ์ดสินค้าตอบสนององศาการขยับของเมาส์แบบ 3 มิติ

### 4. ♻️ Complete Circular Loop: Buyout & Raw Kits
- **รับซื้อขยะรีไซเคิลจากชุมชน:** กรอกส่งขายขยะริมหาด คำนวณเงินสดและ RE:CREDIT รับโบนัส 15%
- **ชุดกล่องวัตถุดิบ (Raw Material Kits):** ให้ผู้สร้างสรรค์สั่งซื้อเศษวัสดุที่ล้างฆ่าเชื้อแล้วไปเริ่มทำตาม Blueprint ได้ทันที
- **Zone Selector Portal:** ระบบเลือกโซนหน้าต่างเดียว รวมทุกบริการของแพลตฟอร์ม

## 🚀 วิธีเปิดใช้งานในเครื่อง (Getting Started)

ไม่ต้องติดตั้ง Dependencies เพิ่มเติม สามารถเปิดใช้งานผ่านเว็บเบราว์เซอร์ได้ทันที:

1. ดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari หรือ Firefox)
2. หรือใช้ Live Server:
   ```bash
   # ผ่าน Python
   python -m http.server 8000
   
   # หรือผ่าน Node npx
   npx serve .
   ```
3. กดปุ่ม **"📷 สแกนขยะ AI"** ที่มุมซ้ายล่าง หรือกดคีย์ลัด **`Alt + S`** เพื่อเปิดห้องควบคุมสแกนเนอร์ AI
